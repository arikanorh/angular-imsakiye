# Yapılacaklar

Şimdilik kenara kaldırılmış, ileride ele alınacak işlerin planları. Her
dosya kendi içinde fazlar, adımlar (`[ ]` / `[~]` / `[x]`) ve "bitti"
ölçütleri taşır. Bir plan işe alınınca kutular bu dosyada işaretlenir,
tamamlanınca dosya silinir (git geçmişinde kalır).
